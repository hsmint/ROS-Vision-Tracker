# main.py 코드 설명 보고서

2026-10-03 · pa06

## 개요

main.py는 라즈베리파이에서 키보드로 입력한 명령을 USB 시리얼로 OpenCR 보드에 보내고, 보드가 보낸 답을 화면에 출력하는 63줄짜리 프로그램입니다. 모터를 직접 움직이지는 않습니다. 명령 해석, 범위 검사, 모터 제어는 모두 OpenCR 펌웨어(opencr_control.ino)가 맡습니다.

프로그램은 두 방향의 데이터를 동시에 처리합니다.
- **보내는 방향:** 키보드 입력 → `send_command()` → USB → OpenCR
- **받는 방향:** OpenCR의 `Serial.println()` → USB → 반복 루프의 수신 부분 → 화면

두 방향을 하나의 반복문에서 번갈아 확인할 수 있는 이유는 `select`가 키보드와 보드 중 데이터가 도착한 쪽을 알려 주기 때문입니다. 그래서 모터가 움직이는 동안에도 보드 메시지를 계속 보여 주면서 새 명령(예: `x` 정지)을 받을 수 있습니다.

## 16~18줄: send_command(), 보드로 명령 보내기

입력한 글자를 보드가 알아듣는 형식으로 바꿔 한 줄 단위로 보냅니다.

```python
def send_command(board, command):
    board.write((command.strip() + "\n").encode("ascii"))
    board.flush()
```

- **16줄:** `board`는 열려 있는 시리얼 포트, `command`는 보낼 글자입니다.
- **17줄:** 세 단계를 한 줄에서 처리합니다.
  - `strip()`: 앞뒤 공백을 지웁니다.
  - `+ "\n"`: 끝에 줄바꿈을 붙입니다. OpenCR은 줄바꿈을 받아야 명령 한 줄이 끝났다고 판단합니다.
  - `encode("ascii")`: 글자를 바이트로 바꿉니다. 한글처럼 ASCII가 아닌 글자가 있으면 `UnicodeEncodeError`가 납니다.
- **18줄:** `flush()`로 모아 둔 데이터를 즉시 내보냅니다.

## 21~27줄: main() 연결 준비

포트를 열고 보드가 준비될 때까지 기다린 뒤, 사용법을 보여 주는 단계입니다.

| 줄 | 코드 | 뜻 |
|---|---|---|
| 21 | `def main():` | 프로그램 본체 함수입니다. |
| 22 | `with serial.Serial(...) as board:` | 시리얼 포트를 엽니다. `with`를 쓰면 프로그램이 끝날 때 포트가 자동으로 닫힙니다. |
| 22 | `timeout=0.1` | 읽을 때 최대 0.1초만 기다립니다. |
| 22 | `write_timeout=2` | 보낼 때 2초 안에 못 보내면 오류로 처리합니다. |
| 23 | `time.sleep(2)` | 2초 기다립니다. 포트를 열면 OpenCR이 재시작될 수 있어 준비 시간을 줍니다. |
| 24~25 | `send_command(board, "")` | 빈 줄을 보내 보드에 반쯤 남아 있던 입력을 끊어 줍니다. |
| 26 | `print(HELP, flush=True)` | 사용법을 출력합니다. `flush=True`는 화면에 바로 표시하라는 뜻입니다. |
| 27 | `pending = bytearray()` | 보드에서 받은 바이트를 한 줄이 완성될 때까지 모아 두는 상자입니다. |

## 29~49줄: 반복 루프

프로그램이 켜져 있는 동안 이 부분을 계속 반복합니다. 한 번 도는 동안 보드 수신과 키보드 입력을 차례로 확인합니다.

### 기다리기 (28~30줄)
- **28줄 `try:`** 아래에서 오류나 Ctrl+C가 생겨도 50줄 이후의 종료 처리로 가게 합니다.
- **29줄 `while True:`** 무한 반복입니다. `break`를 만나야 끝납니다.
- **30줄 `select.select([sys.stdin, board], [], [], 0.2)`** 키보드와 보드를 최대 0.2초 동안 함께 지켜봅니다. 데이터가 온 쪽이 `readable` 목록에 담깁니다. 아무것도 오지 않으면 빈 목록으로 다시 반복합니다.

### 보드에서 데이터가 왔을 때 (31~37줄)

| 줄 | 코드 | 뜻 |
|---|---|---|
| 31 | `if board in readable:` | 보드에서 새 데이터가 왔을 때만 실행합니다. |
| 32 | `board.read(board.in_waiting or 1)` | 도착한 바이트를 모두 읽어 `pending`에 붙입니다. 도착한 수를 모르면 1바이트만 읽습니다. |
| 33 | `while b"\n" in pending:` | 줄바꿈이 있는 동안, 완성된 줄을 하나씩 꺼냅니다. |
| 34 | `pending.partition(b"\n")` | 첫 줄바꿈 앞(`line`)과 뒤(남은 `pending`)로 나눕니다. |
| 35 | `decode("utf-8", errors="replace")` | 바이트를 글자로 바꿉니다. 깨진 바이트는 대체 기호로 바꿔 프로그램이 멈추지 않게 합니다. |
| 36~37 | `if message: print(...)` | 빈 줄이 아니면 화면에 출력합니다. `MOVING XY`, `DONE`, `SAVED` 같은 보드 메시지가 여기서 보입니다. |

### 키보드 입력이 왔을 때 (38~49줄)

| 줄 | 코드 | 뜻 |
|---|---|---|
| 38 | `if sys.stdin in readable:` | 키보드에서 Enter가 눌렸을 때만 실행합니다. |
| 39 | `sys.stdin.readline()` | 입력한 한 줄을 읽습니다. |
| 40~41 | `if not line or ... == "q": break` | 입력이 끝났거나(Ctrl+D) `q`면 반복을 끝냅니다. |
| 42 | `command = line.strip()` | 앞뒤 공백과 줄바꿈을 지웁니다. |
| 43~44 | `if command == "help":` | 보드에 보내지 않고 사용법만 출력합니다. |
| 45~47 | `elif command: send_command(...)` | 빈 줄이 아닌 나머지 명령은 모두 보드로 보냅니다. 명령이 맞는지는 보드가 판단합니다. |
| 48~49 | `except UnicodeEncodeError:` | 한글처럼 ASCII가 아닌 글자를 입력하면 프로그램이 멈추지 않게 안내만 출력합니다. |

## 50~55줄: 종료 처리

어떻게 끝나든 보드에 정지 명령 `x`를 보내, 프로그램을 꺼도 모터가 계속 움직이지 않게 하는 안전장치입니다.

| 줄 | 코드 | 뜻 |
|---|---|---|
| 50~51 | `except KeyboardInterrupt: pass` | Ctrl+C를 눌러도 오류 메시지 없이 조용히 넘어갑니다. |
| 52 | `finally:` | `q`, Ctrl+C, 오류 중 어떤 이유로 끝나든 반드시 실행됩니다. |
| 54 | `send_command(board, "x")` | 보드에 정지 명령을 보냅니다. 펌웨어 V2에서는 이때 현재 위치가 EEPROM에 저장됩니다. |
| 55 | `print("정지 명령 전송, 종료.")` | 종료 사실을 화면에 알립니다. |

이 부분이 끝나면 22줄 `with` 블록을 빠져나면서 시리얼 포트가 자동으로 닫힙니다.

## 58~63줄: 프로그램 시작점

`python3 main.py`로 실행하면 여기서부터 시작합니다. USB 연결 문제를 알기 쉬운 한 줄짜리 메시지로 바꿔 줍니다.

| 줄 | 코드 | 뜻 |
|---|---|---|
| 58 | `if __name__ == "__main__":` | 이 파일을 직접 실행했을 때만 아래를 실행합니다. 다른 파일에서 `import`하면 실행되지 않습니다. |
| 60 | `main()` | 프로그램 본체를 실행합니다. |
| 61 | `except (serial.SerialException, OSError)` | 포트를 찾지 못했거나, 다른 프로그램(시리얼 모니터 등)이 쓰고 있거나, USB가 빠진 경우입니다. |
| 62 | `print(..., file=sys.stderr)` | `시리얼 연결 오류: ...`를 오류 출력으로 내보냅니다. |
| 63 | `sys.exit(1)` | 종료 코드 1(실패)로 끝냅니다. |

## 명령 요약

main.py가 직접 처리하는 명령은 `help`와 `q` 두 개뿐입니다. 나머지는 그대로 보드로 전달됩니다.

| 입력 | 처리하는 곳 | 동작 |
|---|---|---|
| `5 -5 3` | OpenCR | 현재 위치 기준 X +5°, Y -5°를 3°/s로 이동 |
| `h` | OpenCR | Y축부터 X축 순서로 30°/s 홈 복귀 |
| `x` | OpenCR | 정지, 위치 유지, 위치 저장 |
| `off` | OpenCR | 토크 해제. 카메라를 지지한 상태에서 사용 |
| `p` | OpenCR | 펌웨어 버전, 저장 위치, 현재 위치·토크·오류 출력 |
| `scan` | OpenCR | ID11·ID12 모터 상태 조회 |
| `auto on` / `auto off` | OpenCR | 보드 시작 시 홈 복귀 / 저장 위치 복원 설정 |
| `help` | main.py | 사용법 다시 출력 |
| `q` 또는 Ctrl+C | main.py | 보드에 `x`를 보낸 뒤 종료 |

실행 명령은 `python3 /home/pa06/main.py`입니다. 실행 전에 시리얼 모니터를 꺼야 포트 충돌이 없습니다.
