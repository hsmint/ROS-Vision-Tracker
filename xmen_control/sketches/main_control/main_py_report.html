개요

main.py는 라즈베리파이에서 키보드로 입력한 명령을 USB 시리얼로 OpenCR 보드에 보내고, 보드가 보낸 답을 화면에 출력하는 63줄짜리 프로그램입니다. 모터를 직접 움직이지는 않습니다. 명령 해석, 범위 검사, 모터 제어는 모두 OpenCR 펌웨어(opencr_control.ino)가 맡습니다.

프로그램은 두 방향의 데이터를 동시에 처리합니다.

  • 보내는 방향: 키보드 입력 → send_command() → USB → OpenCR

  • 받는 방향: OpenCR의 Serial.println() → USB → 반복 루프의 수신 부분 → 화면

두 방향을 하나의 반복문에서 번갈아 확인할 수 있는 이유는 select가 키보드와 보드 중 데이터가 도착한 쪽을 알려 주기 때문입니다. 그래서 모터가 움직이는 동안에도 보드 메시지를 계속 보여 주면서 새 명령(예: x 정지)을 받을 수 있습니다.

명령은 왼쪽에서 오른쪽으로, 응답은 오른쪽에서 왼쪽으로 흐릅니다. main.py는 가운데에서 글자를 전달만 합니다.

16~18줄: send_command(), 보드로 명령 보내기

입력한 글자를 보드가 알아듣는 형식으로 바꿔 한 줄 단위로 보냅니다.

def send_command(board, command):
    board.write((command.strip() + "\n").encode("ascii"))
    board.flush()

  • 16줄: board는 열려 있는 시리얼 포트, command는 보낼 글자입니다.

  • 17줄: 세 단계를 한 줄에서 처리합니다.

    • strip(): 앞뒤 공백을 지웁니다.

    • + "\n": 끝에 줄바꿈을 붙입니다. OpenCR은 줄바꿈을 받아야 명령 한 줄이 끝났다고 판단합니다.

    • encode("ascii"): 글자를 바이트로 바꿉니다. 한글처럼 ASCII가 아닌 글자가 있으면 UnicodeEncodeError가 납니다.

  • 18줄: flush()로 모아 둔 데이터를 즉시 내보냅니다.

21~27줄: main() 연결 준비

포트를 열고 보드가 준비될 때까지 기다린 뒤, 사용법을 보여 주는 단계입니다.

줄코드뜻

22timeout=0.1읽을 때 최대 0.1초만 기다립니다.

23time.sleep(2)2초 기다립니다. 포트를 열면 OpenCR이 재시작될 수 있어 준비 시간을 줍니다.
24~25send_command(board, "")빈 줄을 보내 보드에 반쯤 남아 있던 입력을 끊어 줍니다.
26print(HELP, flush=True)사용법을 출력합니다. flush=True는 화면에 바로 표시하라는 뜻입니다.

29~49줄: 반복 루프

프로그램이 켜져 있는 동안 이 부분을 계속 반복합니다. 한 번 도는 동안 보드 수신과 키보드 입력을 차례로 확인합니다.

기다리기 (28~30줄)

  • 28줄 try: 아래에서 오류나 Ctrl+C가 생겨도 50줄 이후의 종료 처리로 가게 합니다.

  • 29줄 while True: 무한 반복입니다. break를 만나야 끝납니다.

  • 30줄 select.select([sys.stdin, board], [], [], 0.2) 키보드와 보드를 최대 0.2초 동안 함께 지켜봅니다. 데이터가 온 쪽이 readable 목록에 담깁니다. 아무것도 오지 않으면 빈 목록으로 다시 반복합니다.

보드에서 데이터가 왔을 때 (31~37줄)

줄코드뜻
31if board in readable:보드에서 새 데이터가 왔을 때만 실행합니다.
32board.read(board.in_waiting or 1)도착한 바이트를 모두 읽어 pending에 붙입니다. 도착한 수를 모르면 1바이트만 읽습니다.
33while b"\n" in pending:줄바꿈이 있는 동안, 완성된 줄을 하나씩 꺼냅니다.
34pending.partition(b"\n")첫 줄바꿈 앞(line)과 뒤(남은 pending)로 나눕니다.
35decode("utf-8", errors="replace")바이트를 글자로 바꿉니다. 깨진 바이트는 대체 기호로 바꿔 프로그램이 멈추지 않게 합니다.
36~37if message: print(...)빈 줄이 아니면 화면에 출력합니다. MOVING XY, DONE, SAVED 같은 보드 메시지가 여기서 보입니다.

50~55줄: 종료 처리

어떻게 끝나든 보드에 정지 명령 x를 보내, 프로그램을 꺼도 모터가 계속 움직이지 않게 하는 안전장치입니다.

줄코드뜻
